# Adam Asmaca (Hangman) Oyunu

Bu proje, Java programlama dili ve Swing kütüphanesi kullanılarak NetBeans IDE üzerinde geliştirilmiş, grafiksel kullanıcı arayüzüne (GUI) sahip klasik bir Adam Asmaca oyunudur.

## 🚀 Özellikler

- **Görsel Arayüz (GUI):** Kullanıcı dostu Java Swing arayüzü.
- **Kelime Havuzu:** Dosya tabanlı (I/O) kelime okuma ve eşleştirme mantığı.
- **Kullanıcı Yönetimi:** Dosya tabanlı şifreli/güvenli giriş ve loglama mekanizması.

## 🛠️ Kullanılan Teknolojiler

- **Dil:** Java
- **Arayüz:** Java Swing (NetBeans GUI Builder)
- **Veri Yönetimi:** Java File I/O (Dosya İşlemleri)
